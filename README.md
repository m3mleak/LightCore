# RevisCore plugin for RevisCube

## Build: 
```./gradlew build```
## Run:
```./gradlew runServer```

## Changelog:

### Command Block:
- /sethome -> установка точек дома с проработанной логикой сохранения данных
- /home -> телепортация на установленные точки дома 
- /setspawn -> установка точки спавна с хранением всех параметров точки (admin+)
- /spawn -> тепортация на установленную точку спавна
- /reload -> перезагрузка конфигурации плагина (admin+)
- /setwarp -> установка точки варпа (admin+)
- /warp -> телепортация на точку варпа
- /delhome -> удаление точки дома
- /fly -> включить режим полета (admin+)
- /gm -> смена режима (admin+)
- /ec -> просмотр эндерчеста
- /invsee -> просмотр инвентаря игрока
- /tpa -> телепортация к игроку
- /tpaccept -> принять телепортацию
- /tpdeny -> отклонить телепортацию
- /feed -> Восполнить голод
- /tphere -> телепортация игрока к себе (admin+)
- /tpahere -> отправить запрос на телепортацию к себе
- /tp -> телепортацию к игроку (admin+)
- /wb -> открыть виртуальный верстак
- /day -> установить день
- /night -> установить ночь
- /rain -> установить дождливую погоду
- /sun -> установить солнечную погоду
- /tppos -> телепортация в определенную точку
- /near -> поиск игроков поблизости
- /pay -> перевод монет другому игроку
- /money -> просмотр текущего баланса
- /baltop -> посмотреть топ игроков по балансу
- /moneygive -> выдать монеты игроку (admin+)
- /salary -> получить зарплату
- /hat -> надеть предмет на голову

### Function Block:
- Телепортация на установленную точку спавна при смерти и для новых игроков
- Выдача определенного количества монет при первом заходе игрока
- Отмена телепортаций при получении урона

### Persmissions:
- sethome.set -> установка точки дома
- sethome.unlimited -> установка точек дома без лимита
- reviscore.setspawn -> установка точки спавна
- reviscore.reload -> перезагрузка конфигурации
- reviscore.setwarp -> установка точки варпа
- reviscore.fly -> включить полет
- reviscore.gamemode -> смена режима игры
- reviscore.noncooldown-tpa -> телепортация без кд
- reviscore.cooldown-tpa.* -> телепортация с определенным кд
- reviscore.feed -> Восполнение голода игроку
- reviscore.feed-all -> Восполнение голода любому игроку
- reviscore.tp -> телепортация к игрокам
- reviscore.workbench -> открыть виртуальный верстак
- reviscore.enderchest-open -> открыть эндерчест
- reviscore.invsee -> просмотр чужих инвентарей
- reviscore.enderchest-open-other -> открытие чужих эндерчестов
- reviscore.day -> установить день
- reviscore.night -> установить ночь
- reviscore.sun -> установить ясную погоду
- reviscore.rain -> установить дождливую погоду
- reviscore.tppos -> телепортация в определенную точку
- reviscore.money-see-all -> просмотр баланса всех игроков
- reviscore.givemoney -> выдача монет
- reviscore.near -> поиск игроков неподалеку
